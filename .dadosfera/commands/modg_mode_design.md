# /modg_mode_design

<!-- COMMAND_ID: 053 -->
<!-- COMMAND_VERSION: 1.0.0 -->
<!-- COMMAND_TYPE: mo_mode_design -->

Mode-style command that activates design thinking for long-term system design and architectural evolution.

Provides a mode entrypoint that activates design thinking: investigate long-term system design and integration patterns across repos, create design decision records (DDRs) with detailed trade-off analysis, design cross-system coherence, and coordinate architectural evolution. Focuses on years and generations, not sprints.

## Activation

```bash
/modg_mode_design
```

## Architect Responsibilities

1. **Long-Term System Design**
   - Investigate design patterns
   - Assess system coherence
   - Plan evolution strategy

2. **Architectural Decision Records (ADRs)**
   - Document decisions with rationale
   - Analyze trade-offs
   - Record consequences

3. **Cross-System Integration**
   - Design coherence across repos
   - Plan integration points
   - Coordinate with other systems

4. **Evolution Coordination**
   - Plan years ahead
   - Generational thinking
   - Sustainable architecture
